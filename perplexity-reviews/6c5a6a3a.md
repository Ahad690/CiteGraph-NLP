## Missing Changes

- `get_citations()` and `get_references()` still don’t canonicalize IDs for all edge cases (PMCID, URLs, nonstandard W-ID strings) (`openalex.py:L93,L125`).  
- No persistent run storage beyond in-memory `status_cache` and `results_cache` (`routes.py:L12`), so multi-worker deployments or restarts will lose all state.

## Security & Data Integrity
- **DoS / resource exhaustion**: API allows arbitrary `max_total_papers` and depth in a background task, which can fan out to OpenAlex and consume CPU/memory (`routes.py:L14-L18`).  
- **Data poisoning / scientific corruption**: invalid ID handling in OpenAlex (`openalex.py:L94,L125`) can silently drop or misassign citations, producing incomplete or misleading graphs.  
- **Cross-run contamination risk minimized**: `GraphBuilder.build()` now uses local `graph` instead of `self.graph`. ✅  
- **Unauthorized run access**: UUIDs are public; no tenant/user isolation. Anyone knowing a run_id can access results (`routes.py:L46-L50`).
